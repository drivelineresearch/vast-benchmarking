# Repository artwork

OpenAI's built-in image-generation workflow produced the repository artwork. The image
used by the dashboard and README is
`src/vast_benchmarking/static/vast-benchmarking-header-v2.png`, a text-free technical
illustration of GPU concurrency, effective CPU capacity, memory bandwidth, and disk
throughput using the dashboard's black, graphite, red, and white palette.

The prompt excluded people, logos, vendor marks, text, badges, and watermarks. The older
`vast-benchmarking-banner.png` remains in the repository as an archive. Generated status
badges were removed.

`favicon-source-v1.png` is the square source for the favicon family. Local downsampling
produced the deployed ICO sizes, the 32-pixel PNG, and the 180-pixel Apple touch icon.
